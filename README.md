# Zilin He — personal website

Live address: https://summer114514-hub.github.io/

Static HTML and CSS, published with GitHub Pages from `main` at the repository root. No build step is required. Each project has its own HTML page, so direct links and refreshes work without hash routing.

## Update the website

Edit the relevant HTML file and commit to `main`. Keep project status and personal/AI contribution descriptions accurate. Update `sitemap.xml` when adding or removing pages. Keep `.nojekyll` in the repository root.

## Custom domain

The current deployment uses the free GitHub Pages address. No custom domain is configured. Once a domain is owned, configure it in Settings → Pages before changing DNS, then update canonical URLs, Open Graph URLs, structured data, `robots.txt`, and `sitemap.xml` together. The local `../DEPLOYMENT.md` contains the full deployment guide.
